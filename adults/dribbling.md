# Adults Dribbling Drill

## Purpose
Sharpen ball-handling control, rhythm, and pressure resistance.

## Equipment Needed
- Basketballs
- Cones
- Optional defender

## Instructions
1. Set a cone course with changes of pace and direction.
2. Dribble through with dominant hand, then non-dominant hand.
3. Add combo moves (crossover + retreat + attack).
4. Repeat with a passive defender applying pressure.

## Coaching Tips
- Keep dribble protected with body positioning.
- Use pace changes to create separation.
- Emphasize weak-hand development.
