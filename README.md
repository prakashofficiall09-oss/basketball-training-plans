# Basketball Training Plans
An organized library of basketball drills and practice templates for all ages—kids (6–9), teens (10–15), and adults (16+). Use these starter files to build age-appropriate sessions and share improvements with other coaches.

## Folder Structure
- `kids/` — starter drills and a practice template for ages 6–9.
- `teens/` — starter drills and a practice template for ages 10–15.
- `adults/` — starter drills and a practice template for ages 16+.

Each age group includes:
- `dribbling-drills.md`
- `shooting-drills.md`
- `passing-drills.md`
- `defense-drills.md`
- `practice-template.md`

## Contributing
Coaches can contribute by adding new drills, improving instructions, or sharing full practice plans.
1. Fork the repository and create a new branch.
2. Add your drill to the appropriate age folder.
3. Follow the drill template format so everything stays consistent.
4. Open a pull request with a short description of your changes.

## Sample: Add a New Drill
Add a new drill section or file using the same structure as the starters:

```markdown
# Two-Ball Pound Drill

**Purpose:** Improve ambidextrous ball control and rhythm.

**Equipment Needed:** 2 balls per player.

**Instructions:**
1. Stand in athletic stance with a ball in each hand.
2. Pound both balls at waist height for 20–30 seconds.
3. Switch to alternating pounds and repeat.

**Coaching Tips:** Keep shoulders level, stay low, and maintain a steady pace.
```
