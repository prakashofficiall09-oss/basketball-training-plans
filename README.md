# Basketball Training Plans

This repository contains a structured collection of basketball training plans and drill guides for three age groups:

- [Kids](./kids)
- [Teens](./teens)
- [Adults](./adults)

## How to Use

1. Choose the folder that matches your age group.
2. Open a drill file (dribbling, shooting, passing, or defense).
3. Use the sections in each file to plan your session:
   - Purpose
   - Equipment Needed
   - Instructions
   - Coaching Tips

## Drill Categories Included

Each age group currently includes starter files for:

- Dribbling
- Shooting
- Passing
- Defense

You can expand each file with difficulty progressions, timing, and team-specific variations.
