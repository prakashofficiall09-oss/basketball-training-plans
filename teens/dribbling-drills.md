# Zigzag Dribble Drill

**Purpose:** Build control at speed with change-of-direction moves.

**Equipment Needed:** 6–8 cones, 1 ball per player.

**Instructions:**
1. Set cones 6–8 feet apart from baseline to half court.
2. Dribble to each cone and use a crossover or inside-out move.
3. Go down and back each hand, then one trip at game speed.

**Coaching Tips:** Stay low, protect the ball, and accelerate after each move.
