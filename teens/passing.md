# Teens Passing Drill

## Purpose
Improve passing under pressure and decision-making speed.

## Equipment Needed
- Basketballs
- Cones
- Optional defender

## Instructions
1. Form groups of 3 in a triangle.
2. Pass and follow the pass to the next cone.
3. Add a defender to contest passing lanes.
4. Increase tempo while maintaining pass accuracy.

## Coaching Tips
- Pass early before pressure arrives.
- Use pass fakes to create angles.
- Keep spacing and communicate clearly.
