# Teens Dribbling Drill

## Purpose
Build tighter handle, change-of-direction control, and game-speed dribbling.

## Equipment Needed
- 1 basketball per player
- Cones (6-8)
- Court space

## Instructions
1. Set cones in zig-zag formation.
2. Dribble through using crossover at each cone.
3. Repeat using between-the-legs or behind-the-back moves.
4. Finish with a timed full-court dribble sprint.

## Coaching Tips
- Keep dribble low and tight.
- Sell direction changes with shoulders and hips.
- Push speed while keeping control.
